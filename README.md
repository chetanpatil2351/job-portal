# 💼 Job House - Local Job Portal

A full-stack job portal web application developed using Python, Flask, and PostgreSQL. The platform connects job seekers and recruiters through a modern, responsive interface with secure authentication and job management features.

---

## 🚀 Features

- 🔐 User Registration & Login
- 🔒 Secure Password Hashing (Flask-Bcrypt)
- 👤 Role-Based Authentication
- 💼 Job Posting
- 🔍 Search Jobs
- 📄 Apply for Jobs
- ❤️ Save Jobs
- 📋 My Applications
- 🏢 Recruiter Dashboard
- 👥 View Applicants
- 📊 Dashboard Statistics
- 🔔 Notifications
- 👤 User Profile Management
- 📱 Responsive UI

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/Job-House.git
```

### Move to Project

```bash
cd Job-House
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure Environment Variables

Create a `.env` file:

```env
SECRET_KEY=your_secret_key
DATABASE_URL=your_postgresql_database_url
```

### Run Application

```bash
python app.py
```
